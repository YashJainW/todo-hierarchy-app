# Quicksand Font Setup

## Download Instructions

To use the Quicksand font in this app, you need to download the font files from Google Fonts:

### Steps:

1. Visit [Google Fonts - Quicksand](https://fonts.google.com/specimen/Quicksand)

2. Click "Download family" to get all font files

3. Extract the downloaded zip file

4. Copy the following `.ttf` files to this directory (`assets/fonts/`):
   - `Quicksand-Light.ttf`
   - `Quicksand-Regular.ttf`
   - `Quicksand-Medium.ttf`
   - `Quicksand-SemiBold.ttf`
   - `Quicksand-Bold.ttf`

5. Make sure the filenames match exactly (case-sensitive):
   - `Quicksand-Light.ttf`
   - `Quicksand-Regular.ttf`
   - `Quicksand-Medium.ttf`
   - `Quicksand-SemiBold.ttf`
   - `Quicksand-Bold.ttf`

6. Restart your Expo development server after adding the fonts

### Quick Setup (Using Google Fonts Helper)

1. Visit https://fonts.google.com/specimen/Quicksand
2. Click on each weight you need (Light, Regular, Medium, SemiBold, Bold)
3. Use the "Download all" option or download each weight individually
4. Extract the `.ttf` files to this directory

Once the fonts are in place, restart the app and the Quicksand font will be applied throughout!
